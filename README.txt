个人学术主页 — 编辑说明

直接用浏览器打开 index.html 即可，无需安装或编译。

文件用途
  index.html         个人简介、照片说明、研究方向、代表成果、学术经历
  publications.html  精选论文、完整论文列表、Altmetric 和 Dimensions 徽章
  tools.html         工具和数据库介绍
  style.css          三个页面共用的配色、字体大小、布局与手机适配
  images/            图片素材

编辑提示
  HTML 和 CSS 已采用两空格缩进与换行。
  在 HTML 中搜索可见标题，可快速定位对应段落。
  修改字号：在 style.css 中搜索 font-size。
  修改配色：在 style.css 顶部修改 :root 中的颜色值。
  添加论文时，保持 DOI 链接与两个徽章的 data-doi 一致。
  Altmetric 和 Dimensions 需联网加载；无记录时沿用自动隐藏设置。

本目录是独立预览副本，原网站文件夹未修改。
